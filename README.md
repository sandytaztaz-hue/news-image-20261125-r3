Sum up 25 November's world news in one image

A one-page 1024x1024 broadsheet drawn with PIL: 39 stories dated Wednesday
25 November 2026 across 7 regions, with a masthead, an 8-number stat strip,
a UTC timeline ruler, 3 hero stories, 10 illustrated secondary stories, a
numbered 26-story list, a pinned world map, and a date-check box that names
the older stories left out on purpose. `render.py` draws `entry.png`;
`main.py` (standard library only) copies it byte-identical to the output
directory.

## Run it

```sh
python3 render.py
python3 main.py
```
